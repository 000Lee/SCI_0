# 척수손상(spinal cord injury, SCI) 재활 — 0단계. 방향 잡기

> 대상: 뇌병변(brain lesion) 경험은 충분하나 척수손상 경험이 없는 물리치료사(physical therapist, PT)
> 목적: 회복기 재활병동(convalescent rehabilitation ward) 근무 전 사고방식 전환

---

## 1. 뇌병변 vs 척수손상 — 무엇이 근본적으로 다른가

### ① 정의

| | 뇌병변(brain lesion) | 척수손상(spinal cord injury, SCI) |
|---|---|---|
| 병소 위치 | 대뇌·소뇌·뇌줄기(brainstem) | 척수(spinal cord) |
| 대표 질환 | 뇌졸중(stroke), 외상성 뇌손상(traumatic brain injury, TBI), 파킨슨병(Parkinson's disease) | 외상성 척수손상, 척수종양, 척수경색 |
| 손상 형태 | 판(sheet)의 일부 | 케이블(cable)이 특정 높이에서 가로로 절단 |

### ② 기전 — 왜 다른가

뇌는 **넓은 판**, 척수는 **좁은 케이블 다발**이다.

- 뇌졸중은 판의 일부가 손상 → 옆 영역이 대신 떠맡는 신경가소성(neuroplasticity)이 회복의 주 기전
- 척수손상은 케이블이 어느 높이에서 끊겼는지가 전부. 우회로가 거의 없다

> **뇌졸중 재활 = 회복(recovery) 중심 — "이 팔을 다시 쓰게 만든다"**
> **척수손상 재활 = 보상(compensation) 중심 — "남은 근육으로 그 일을 해내는 법을 만든다"**

### ③ 임상양상 — 7가지 결정적 차이

**(1) 마비의 기하학**

- 뇌졸중: 편마비(hemiplegia) — 세로로 나뉨
- 척수손상: 사지마비(tetraplegia) / 하반신마비(paraplegia) — **가로로 나뉨**, 좌우 대칭
- 척수손상에는 **레벨(level)** 개념이 있고 뇌졸중에는 없다. 레벨을 말하지 못하면 그 환자를 모르는 것

**(2) 감각**

- 뇌졸중: 부분적 저하. 환자가 "덜 느껴진다"고 말해준다
- 척수손상: 레벨 아래 **완전 소실** 가능
- 결과: 화상, 골절, 과신전(hyperextension), 욕창(pressure injury)이 **통증 없이** 발생
- **치료사가 눈으로 확인하는 것 외에 방법이 없다**

**(3) 자율신경계(autonomic nervous system)**

- 뇌졸중: 치료 스케줄에 거의 영향 없음
- 척수손상: **방광·장·혈압·체온이 치료 시간을 지배한다**
- 자율신경 반사부전(autonomic dysreflexia, AD)은 응급이며 사망 가능

**(4) 인지·언어**

- 뇌졸중: 실어증(aphasia), 편측무시(unilateral neglect), 인지장애가 학습을 방해
- 척수손상: **대개 인지가 온전** → 환자 교육(patient education)이 치료의 절반
- 단, 외상성 척수손상은 외상성 뇌손상 동반률이 낮지 않다. 교통사고·추락 환자가 말귀를 못 알아들으면 동반 뇌손상 의심

**(5) 남은 근육을 대하는 태도**

- 뇌졸중: 마비측 회복 여지가 있어 건측 과사용을 경계
- 척수손상: 남은 근육이 **평생 그것뿐**. C6 손상 환자는 어깨와 손목폄근으로 수십 년을 산다
- **어깨 보호(shoulder preservation)가 장기 예후를 좌우한다.** 어깨돌림근띠(rotator cuff) 손상 = 독립성 상실

**(6) 경직(spasticity)의 의미**

- 뇌졸중: 비교적 일정. 자세·감정·피로에 따라 변동
- 척수손상: 폄근 연축(extensor spasm)이 강하고 **유해자극(noxious stimulus)에 즉각 반응**
- **"오늘 경직이 갑자기 심하다" = 검사 신호.** 늘리기로 대응할 게 아니라 원인(방광 팽만, 요로감염, 욕창, 파고든 발톱)을 찾는다

**(7) 구축(contracture)을 대하는 태도 — 정반대인 지점**

- 뇌졸중: 모든 구축은 막는다
- 척수손상 C6~C7: **손가락 굽힘근의 약간의 단축을 의도적으로 남긴다**
  → 손목폄(wrist extension) 시 손가락이 저절로 굽는 **텐노데시스 잡기(tenodesis grasp)** 확보
  → 여기서 손가락을 열심히 펴서 늘려놓으면 환자의 잡기 기능을 없애는 것

### ④ 치료실 대응 — 지금 당장 바꿔야 할 3가지

1. 환자를 **"레벨 + 완전/불완전 + 위험요소"**로 파악 (예: "C6 AIS A, T6 이상 → AD 위험")
2. 세션 전 **방광·장·피부**를 확인하고 시작
3. **"정상 움직임"을 목표로 잡지 않는다.** 배근육(abdominal muscle) 없는 환자는 팔로 균형을 만든다

## 2. 상위운동신경세포(UMN) / 하위운동신경세포(LMN)

### ① 정의

- **상위운동신경세포(upper motor neuron, UMN)**: 대뇌겉질 운동영역 → 겉질척수로(corticospinal tract) → 척수 앞뿔(anterior horn). **중추신경계 내부에만 존재**
- **하위운동신경세포(lower motor neuron, LMN)**: 앞뿔세포(anterior horn cell) → 앞뿌리(ventral root) → 말초신경(peripheral nerve) → 근육. 근육으로 가는 **최종공통경로(final common pathway)**

### ② 기전

- **UMN 손상**: 앞뿔세포는 생존. 위에서 내려오던 **억제(inhibition)만 소실** → 반사궁(reflex arc)이 브레이크 없이 작동 → 반사 항진, 경직
- **LMN 손상**: 근육-신경 완전 단절 → 반사궁 자체 소실 → 이완마비(flaccid paralysis), 신경성 위축

### ③ 임상양상 대비

| 항목 | UMN 손상 | LMN 손상 |
|---|---|---|
| 근긴장 | 경직(spasticity) 증가 | 이완(flaccid) |
| 깊은힘줄반사(deep tendon reflex, DTR) | 항진 | 소실 |
| 병적반사 | 바빈스키(Babinski) 양성, 발목간대(ankle clonus) | 없음 |
| 위축 | 폐용성, 느리고 경함 | 신경성, 빠르고 심함 |
| 근섬유다발수축(fasciculation) | 없음 | 있을 수 있음 |
| 방광 | 반사성(경직성) 방광 | 이완성 방광 |
| 장 | 반사성 장 — 좌약·손가락 자극 유효 | 이완성 장 — 손으로 배변 제거 필요 |
| 기능적 전기자극(FES) | 반응함 | **반응 안 함** |

### ④ 척수손상에서의 실전 포인트

**한 환자 안에 UMN과 LMN이 섞여 있다.**

C6 척수손상의 경우:
- **C6 분절 자체**: 앞뿔세포 손상 → **LMN 양상**(이완, 빠른 위축)
- **C7 이하**: 앞뿔세포는 생존, 하행 신호만 차단 → **UMN 양상**(경직, 반사 항진)

**해부학적 필수 지식 2가지**

1. 척수는 성인에서 **첫째~둘째 허리뼈(L1~L2 vertebra)** 높이에서 끝난다 → 이 끝이 척수원뿔(conus medullaris)
2. 그 아래는 신경뿌리 다발뿐 → **말총(cauda equina)** = 말초신경 = **순수 LMN**

→ 가슴허리이음부(thoracolumbar junction) 이하 손상 환자는 **경직이 없고 반사가 소실된 것이 정상**. 항경직 치료 무의미, FES 반응 없음. 반면 욕창 위험은 더 높다

**⚠ 함정: 척수쇼크(spinal shock)**
급성기에는 UMN 손상이어도 반사가 전부 소실된다. 이 시기에 "이완성이니 LMN"이라고 판단하면 틀린다

## 3. 회복기 재활병동에서 척수손상 환자의 하루

> **척수손상 환자의 하루는 치료 스케줄이 아니라 방광·장 스케줄을 중심으로 돌아간다**

### 시간대별 요점

**아침 (기상~오전)**
- 밤새 누워 있었으므로 **기립성 저혈압(orthostatic hypotension)** 위험 최고
- 복대(abdominal binder), 압박스타킹(compression stocking) 착용 확인
- 배변 프로그램(bowel program)이 아침인 환자 다수, 30~60분 소요 → 이 시간에 치료 잡으면 취소된다

**간헐적 도뇨(intermittent catheterization, IC)**
- 통상 4~6시간 간격 (**병원 지침·환자별 오더 확인 필요**)
- **도뇨 직전** = 방광 최대 팽만 = AD 위험 최고, 경직 최고 → 치료 효율 최저
- **도뇨 직후 1~2시간이 골든타임**

**압력 분산(pressure relief)**
- 흔히 15~30분마다 30초~1분 권고하나 문헌마다 다름 — **병원 지침 확인 필요**
- **치료 중에도 이 시계는 돌아간다.** 세션 안에 자세 변경을 포함시킨다

**어깨 부하 분배**
- 휠체어 추진(propulsion) + 옮겨앉기(transfer) 훈련을 하루에 몰아넣지 않는다
- 작업치료(occupational therapy) 세션 내용까지 포함해 **하루 총 부하**를 본다

### 세션 시작 전 체크리스트

**매 세션 직접 확인 (치료사 본인)**
1. **피부** — 엉치뼈(sacrum), 궁둥뼈결절(ischial tuberosity), 발꿈치(heel), 보조기 접촉부
2. **경직이 평소와 다른가** — 갑작스러운 증가는 몸 어딘가의 문제 신호
3. **환자의 주관적 컨디션** — 두통, 어지럼, 오한, 평소와 다른 느낌

**기록·인계로 확인 (매번 물을 필요 없음)**
4. 오늘 혈압 + **이 환자의 기저 혈압** (목척수손상은 수축기 90~110mmHg가 흔함)
5. 마지막 도뇨 시각·배뇨량, 소변줄 꼬임 여부
6. 마지막 배변 시각

**한 번 확인 후 계속 적용**
7. **척추 안정성과 보조기 착용 지침** — 수술 후 굽힘(flexion)·회전(rotation) 제한 여부. **주치의 오더와 병원 지침 반드시 확인**

## ⚠ 위험 — 자율신경 반사부전(autonomic dysreflexia, AD)

**대상**: 제6등뼈신경(T6) 이상 손상 환자 (드물게 T6~T8)

**판단 기준**
- 수축기혈압이 **환자 기저치보다 20~40mmHg 이상 상승**
- 갑작스럽고 심한 **박동성 두통**
- 손상 레벨 **위쪽**: 얼굴 홍조, 발한, 코막힘
- 손상 레벨 **아래쪽**: 창백, 소름, 서늘함
- 서맥(bradycardia)이 흔하나 빈맥일 수도 있음
- 흐릿한 시야, 불안감

**즉시 조치 순서**
1. **치료 중단**
2. **앉힌다** (등받이 세우고 다리 내림) — **절대 눕히지 않는다**
3. **조이는 것 전부 푼다** — 복대, 압박스타킹, 벨트, 신발, 보조기, 꽉 낀 바지
4. **원인 탐색** — 방광 팽만(1위), 소변줄 꼬임·막힘, 변 정체, 욕창, 파고든 발톱, 깔고 앉은 물건
5. **간호사·의사 즉시 호출**, 혈압 **5분 간격** 측정
6. 이후 약물 대응은 **병원 프로토콜 확인 필요**

**⚠ 뇌졸중과 정반대인 지점**
뇌졸중 병동에서는 두통·안색 변화 시 눕히고 안정시킨다. **AD에서 눕히면 혈압이 더 올라가 악화된다.** 방치 시 뇌출혈, 경련, 사망 가능

## 4. 보충 — 자주 걸리는 개념

### 자율신경 문제가 있는지 어떻게 아는가

**해부학적 근거**
- 교감신경(sympathetic): 척수 **T1~L2** 곁뿔(lateral horn)에서 나감
- 부교감신경(parasympathetic): 뇌줄기의 미주신경(vagus nerve) + **S2~S4**
- 미주신경은 뇌신경이라 **척수손상과 무관하게 살아남는다** → 교감 브레이크만 사라짐 → 서맥 경향

**레벨별 위험도**

| 손상 레벨 | 자율신경 상태 |
|---|---|
| T6 이상 | 내장혈관 조절(splanchnic, T5~L2)이 뇌 통제에서 분리 → **AD, 기립성 저혈압, 서맥, 체온조절 장애 모두 고위험** |
| T6~L2 | 중간. 일부 교감 유출 보존 |
| L2 이하 | 교감 유출은 대부분 보존. AD 위험 낮음. 단 방광·장(S2~S4)은 여전히 문제 |

**치료실에서의 판단 지표**
1. 손상 레벨이 T6 이상인가
2. 기저 수축기혈압이 90~110mmHg로 낮은가
3. 손상 부위 **아래로 땀이 안 나는가** (위쪽만 땀이 나는 보상성 발한)
4. 앉히거나 세우면 혈압이 떨어지는가
5. 방광이 찼을 때 두통·얼굴 홍조가 생기는가
6. 체온이 실내 온도를 따라가는가 — 체온조절 장애(poikilothermia)

※ 공식 평가도구로 **ISAFSCI**(International Standards to document remaining Autonomic Function after SCI)가 있으나 국내 임상 활용도는 병원마다 다름

### 폄근 연축(extensor spasm)

- **정의**: 엉덩관절·무릎이 갑자기 쭉 펴지며 뻣뻣해지는 발작적 불수의 수축. **"뻗친다"가 맞다**
- **뇌졸중과 대비**: 뇌졸중 하지도 폄근 우세이나 **지속적 자세 경향**. 척수손상은 **발작적**이며 유해자극에 튀어나옴
- **반대 유형**: 굽힘근 연축(flexor spasm) — 다리가 확 당겨 올라옴. 척수원뿔 근처 손상에서 흔함
- **⚠ 위험**: 옮겨앉기(transfer) 도중 폄근 연축이 나오면 환자가 밀려 떨어진다. 매트 위에서 미리 유발 패턴을 파악해 둔다
- **⚠ 양날의 검**: 일부 환자는 폄근 연축을 이용해 기립·옮겨앉기를 한다. **무조건 없애면 기능을 뺏는 것**

### UMN과 LMN이 하나만 손상되는 경우

**순수 LMN만 손상**
- 말총증후군(cauda equina syndrome) — 첫째~둘째 허리뼈(L1~L2) 이하 손상
- 신경뿌리 손상, 말초신경 손상
- → 이완마비, 반사 소실, 경직 없음, FES 반응 없음

**사실상 순수 UMN처럼 보이는 경우**
- 가슴척수(T2~T12) 손상: 손상분절 1~2개는 LMN이지만 그 분절이 지배하는 근육이 갈비사이근(intercostal)·몸통근육이라 **임상적으로 확인이 어려움** → 다리 전체가 UMN 양상으로만 보인다

**혼재가 눈에 보이는 경우**
- 손상 레벨이 **팔다리 근육을 지배하는 분절**에 걸칠 때: C5~T1(팔), L2~S2(다리)
- 예) C6 손상 → C6 근육은 이완성 위축(LMN), C7 이하는 경직(UMN)

**정리**: 손상 위치에 따라 결정된다. 가슴척수는 UMN만 보이고, 목척수와 허리척수는 혼재가 보이고, 척수원뿔 아래는 LMN만 보인다

### 가슴허리이음부(thoracolumbar junction)

- **위치**: 대략 제10등뼈~제2허리뼈(T10~L2)
- **왜 중요한가**
  1. 갈비뼈로 고정된 등뼈(thoracic spine)와 가동성이 큰 허리뼈(lumbar spine)가 만나는 지점 → **외상 시 골절 호발 부위**
  2. 척수원뿔(conus medullaris)이 여기(L1~L2 높이)에 위치
  3. → 한 번의 골절로 **척수원뿔 + 말총이 동시에** 손상될 수 있음
- **결과**: 척수원뿔증후군(conus medullaris syndrome), 말총증후군(cauda equina syndrome), 또는 둘의 혼합. UMN/LMN 소견이 뒤섞이거나 순수 LMN으로 나타난다

## 0단계 요약 — 마인드 전환 3줄

1. **레벨이 전부다.** "레벨 + 완전/불완전 + 위험요소"로 파악하는 습관
2. **회복이 아니라 보상이 주무기다.** 남은 근육으로 해내는 법을 설계
3. **자율신경이 치료 스케줄을 지배한다.** 방광·장·혈압·피부 확인 없이 시작하는 세션은 없다
